# Лабораторна робота №1: Data-Oriented Programming у Java

Предметна модель сповіщень із незмінними `record`-типами, закритою ієрархією `sealed interface` та окремим обробником. Проєкт виконано для дисципліни «Технології розробки на платформі Java».

## Варіант

Номер залікової книжки — **4103**. За формулою `V = N mod 3`: `4103 mod 3 = 2`. Отже, реалізовано варіант **V=2**, модель `Notification` із типами `TextMsg`, `ImageMsg`, `AudioMsg`.

## Вимоги

- JDK 21 або новіший;
- Apache Maven 3.9 або новіший.

## Запуск тестів

```bash
mvn test
```

Тести JUnit 5 перевіряють усі три гілки `switch`, точний формат повідомлень, `null`-аргумент обробника та некоректні значення кожного поля записів. Код розміщено в пакеті `ua.kpi.comsys.dop`.
